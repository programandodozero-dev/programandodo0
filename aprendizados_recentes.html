Variáveis e Tipos de Dados (Python)

O que são variáveis?

Variáveis são espaços utilizados para armazenar informações dentro de um programa.

Pense em uma variável como uma caixa onde você pode guardar um valor para utilizar mais tarde.

Por exemplo, podemos criar uma variável para guardar um nome: 

nome = "Manuel"
  1. nome é o nome da variável
  2. = significa "receber"
  3. "Manuel e o valor armazenado"

Como criar variáveis

Criar uma variável em Python é simples. Basta escolher um nome e atribuir um valor.

   nome = "João"
idade = 20
   altura = 1.75

nome = "João" --> Cria uma variável chamada nome e guarda o texto "João".
idade = 20 --> Cria uma variável chamada idade e guarda o número inteiro 20.
altura = 1.75 --> Cria uma variável chamada altura e guarda o número decimal 1.75.

Principais tipos de dados

Python possui vários tipos de dados. Os mais usados por iniciantes são:

String (str)

Utilizada para armazenar textos.

nome = "Maria"
   cidade = "Luanda"

Tudo que estiver entre aspas é considerado texto.

Inteiro (int)

Utilizado para números sem casas decimais.

idade = 18
ano = 2025

Decimal (float)

Utilizado para números com casas decimais.

  altura = 1.70
peso = 65.5

Booleano (bool)

O tipo booleano possui apenas dois valores:

True --> significa verdadeiro.
False --> significa falso. 

estudando = True
aprovado = False

Exibindo valores com print()

A função print() é utilizada para mostrar informações na tela.

   nome = "João"
idade = 20
 print(nome)
  print(idade)

nome = "João" --> Guarda o nome João.
idade = 20 --> Guarda a idade 20.
print(nome) --> Mostra na tela o valor armazenado na variável nome.
print(idade) -->Mostra na tela o valor armazenado na variável idade.

Resultado:
João
20

Entrada de Dados (input)

O que é input()?

A função input() é utilizada para receber informações digitadas pelo usuário durante a execução do programa.

Enquanto uma variável comum guarda um valor definido pelo programador, o input() permite que o próprio usuário forneça esse valor.

Exemplo:

nome = input("Digite o seu nome: ")

Quando o programa for executado, ele exibirá a mensagem:

Digite o seu nome:
E ficará aguardando o usuário digitar uma resposta.

Como receber dados do usuário

Podemos utilizar o input() para solicitar qualquer informação.

nome = input("Digite o seu nome: ")

input() --> recebe um valor digitado pelo usuário.
"Digite o seu nome: " --> é a mensagem exibida na tela.
O valor digitado é armazenado na variável nome.

Armazenando a entrada em variáveis

Os dados digitados pelo usuário podem ser guardados em variáveis para serem utilizados posteriormente. 

nome = input("Digite o seu nome: ")
    cidade = input("Digite a sua cidade: ")

nome = input("Digite o seu nome: ") --> Solicita o nome e armazena a resposta na variável nome.
cidade = input("Digite a sua cidade: ") --> Solicita a cidade e armazena a resposta na variável cidade.

Exibindo os dados recebidos

Depois de receber os dados, podemos exibi-los utilizando a função print().

                        nome = input("Digite o seu nome: ")
print(nome)

nome = input("Digite o seu nome: ") --> Recebe o nome digitado pelo usuário.
print(nome) --> Mostra na tela o valor armazenado na variável nome.
