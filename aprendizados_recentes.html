Variáveis e Tipos de Dados (Python)

O que são variáveis?

Variáveis são espaços utilizados para armazenar informações dentro de um programa.

Pense em uma variável como uma caixa onde você pode guardar um valor para utilizar mais tarde.

Por exemplo, podemos criar uma variável para guardar um nome: 

nome = "Manuel"
  1. nome --> é o nome da variável
  2. = --> significa "receber"
  3. "Manuel" --> é o valor armazenado"

Como criar variáveis

Criar uma variável em Python é simples. Basta escolher um nome e atribuir um valor.

   nome = "João"
   idade = 20
   altura = 1.75
  1. nome = "João" --> Cria uma variável chamada nome e guarda o texto "João".
  2. idade = 20 --> Cria uma variável chamada idade e guarda o número inteiro 20.
  3. altura = 1.75 --> Cria uma variável chamada altura e guarda o número decimal 1.75.

Principais tipos de dados

Python possui vários tipos de dados. Os mais usados por iniciantes são:

String (str)

Utilizada para armazenar textos.

nome = "Maria"
cidade = "Luanda"

Tudo que estiver entre aspas é considerado texto.

Inteiro (int)

Utilizado para números sem casas decimais.

idade = 18
ano = 2025

Decimal (float)

Utilizado para números com casas decimais.

altura = 1.70
peso = 65.5

Booleano (bool)

O tipo booleano possui apenas dois valores:

  1. True --> significa verdadeiro.
  2. False --> significa falso.
estudando = True
aprovado = False

Exibindo valores com print()

A função print() é utilizada para mostrar informações na tela.

 nome = "João"
 idade = 20
 print(nome)
 print(idade)
  1. nome = "João" --> Guarda o nome João.
  2. idade = 20 --> Guarda a idade 20.
  3. print(nome) --> Mostra na tela o valor armazenado na variável nome.
  4. print(idade) -->Mostra na tela o valor armazenado na variável idade.

Resultado:
João
20

Exemplo Prático

Vamos criar um pequeno cadastro.

nome = "Ana"
idade = 19
cidade = "Luanda"

print("Nome:", nome)
print("Idade:", idade)
print("Cidade:", cidade)

Resultado:
Nome: Ana

Cidade: Luanda

Entrada de Dados (input)

O que é input( )?

A função input() é utilizada para receber informações digitadas pelo usuário durante a execução do programa.

Enquanto uma variável comum guarda um valor definido pelo programador, o input() permite que o próprio usuário forneça esse valor.

Exemplo

nome = input("Digite o seu nome: ")

Quando o programa for executado, ele exibirá a mensagem:

Digite o seu nome:
E ficará aguardando o usuário digitar uma resposta.

Como receber dados do usuário

Podemos utilizar o input() para solicitar qualquer informação.

nome = input("Digite o seu nome: ")
  1. input() --> recebe um valor digitado pelo usuário.
  2. "Digite o seu nome: " --> é a mensagem exibida na tela.
  3. O valor digitado é armazenado na variável nome.

Armazenando a entrada em variáveis

Os dados digitados pelo usuário podem ser guardados em variáveis para serem utilizados posteriormente. 

nome = input("Digite o seu nome: ")
cidade = input("Digite a sua cidade: ")
  1. input("Digite o seu nome: ") --> Solicita o nome e armazena a resposta na variável nome.
  2. input("Digite a sua cidade: ") --> Solicita a cidade e armazena a resposta na variável cidade.

Exibindo os dados recebidos

Depois de receber os dados, podemos exibi-los utilizando a função print().

nome = input("Digite o seu nome: ")
print(nome)
  1. nome = input("Digite o seu nome: ") --> Recebe o nome digitado pelo usuário.
  2. print(nome) --> Mostra na tela o valor armazenado na variável nome.

Operações Matemáticas

O que são operações matemáticas?

As operações matemáticas permitem realizar cálculos dentro dos programas. Em Python, podemos utilizar operadores matemáticos para somar, subtrair, multiplicar, dividir e muito mais.

Soma (+)

O operador '+' é utilizado para somar valores.

numero1 = 10
numero2 = 5 
resultado = numero1 + numero2 

print(resultado)
  1. numero1 = 10 --> Guarda o valor 10.
  2. numero2 = 5 --> Guarda o valor 5.
  3. resultado = numero1 + numero2 --> Soma os dois valores e guarda o resultado.
  4. print(resultado) --> Mostra o resultado na tela.

Resultado
15

Subtração (-)

O operador '-' é utilizado para subtrair valores.

numero1 = 10
numero2 = 5 
resultado = numero1 - numero2 

print(resultado)

Resultado
5

Multiplicação (*)

O operador '*' é utilizado para multiplicar valores.

numero1 = 10
numero2 = 5 
resultado = numero1 * numero2 

print(resultado)

Resultado
50

Divisão (/)

O operador '/' é utilizado para dividir valores.

numero1 = 10
numero2 = 5 
resultado = numero1 / numero2 

print(resultado)

Resultado
5.0
Observe que a divisão normalmente retorna um número decimal.

Potência (**)

O operador '**' é utilizado para calcular potências.

numero = 2
resultado = numero ** 3
print(resultado)

2 ** 3
Significa: 2 × 2 × 2
Resultado: 8

Resto da Divisão (%)

O operador '%' retorna o resto de uma divisão.

numero1 = 10
numero2 = 3
resultado = numero1 % numero2 

print(resultado)

10 ÷ 3 = 3
Resto = 1
Resultado: 1

Operadores de Comparação

O que são operadores de comparação?

Os operadores de comparação são utilizados para comparar valores.
O resultado de uma comparação será sempre:
'True' --> (verdadeiro)
'False' --> (falso)

Esses operadores são muito importantes, principalmente com as estruturas condicionais.

Igual a (==)

O operador '==' verifica se dois valores são iguais.

numero = 10
print(numero == 10)
  1. numero = 10 --> Cria uma variável com o valor 10.
  2. print(numero == 10) --> Verifica se o valor de 'numero' é igual a 10.

Resultado: True

Diferente de (!=)

O operador '!=' verifica se dois valores são diferentes.

numero = 10
print(numero != 5)
  1. O Python verifica se 10 é diferente de 5.

Resultado: True

Outro exemplo:

print(numero != 10)

Resultado: False
Porque os valores são iguais.

Maior que (>)

O operador '>' verifica se um valor é maior que outro.

idade = 20
print(idade > 18)

Resultado: True
Porque 20 é maior que 18.

Menor que (<)

O operador '<' verifica se um valor é menor que outro.

idade = 15
print(idade < 18)

Resultado: True
Porque 15 é menor que 18.

Maior ou igual a (>=)

O operador '>=' verifica se um valor é maior ou igual ao outro.

idade = 18
print(idade >= 18)

Resultado: True
Porque 18 é igual a 18.

Outro exemplo:

idade = 20
print(idade >= 18)

Resultado:True
Porque 20 é maior que 18.

Menor ou igual a (<=)

O operador '<=' verifica se um valor é menor ou igual ao outro.

idade = 18
print(idade <= 18)

Resultado: True
Porque 18 é igual a 18.

Outro exemplo:

idade = 15
print(idade <= 18)

Resultado:True
Porque 15 é menor que 18.

Condicionais (if, elif, else)

O que são condicionais?

As condicionais permitem que um programa tome decisões.
Dependendo de uma condição ser verdadeira ou falsa, o programa executará diferentes ações.

Imagine a seguinte situação:
• Se a idade for maior ou igual a 18 -> pode entrar.
• Caso contrário -> não pode entrar.

É exatamente isso que as estruturas condicionais fazem.

Estrutura 'if'

O 'if' é utilizado quando queremos executar uma ação somente se uma condição for verdadeira.

Exemplo

idade = 20
if idade >= 18:
    print("Você é maior de idade.")
  1. idade = 20 --> Cria uma variável com o valor 20.
  2. if idade >= 18: --> Verifica se a idade é maior ou igual a 18.
  3. print("Você é maior de idade.") --> Será executado apenas se a condição for verdadeira.

Resultado: Você é maior de idade.

A importância da indentação

Em Python, os blocos de código dentro do 'if' devem estar recuados.

Exemplo correto:

idade = 20
if idade >= 18:
    print("Você é maior de idade.")

Exemplo incorreto:

idade = 20
if idade >= 18:
print("Você é maior de idade.")

Sem a indentação o Python gerará um erro.

Estrutura 'else'

O 'else' é utilizado quando queremos executar uma ação caso a condição seja falsa.

Exemplo

idade = 16
if idade >= 18:
    print("Você é maior de idade.")
else:
    print("Você é menor de idade.")

Se a idade for maior ou igual a 18: Você é maior de idade.
Caso contrário: Você é menor de idade.

Resultado: Você é menor de idade.

Estrutura 'elif'

O 'elif' é utilizado quando queremos verificar uma nova condição caso a condição anterior seja falsa.

Exemplo

nota = 15
if nota >= 16:
    print("Excelente")
elif nota >= 10:
    print("Aprovado")
else:
    print("Reprovado")
  1. nota = 15 --> Cria uma variável com o valor 15.
  2. if nota >= 16: --> Verifica se a nota é maior ou igual a 16.
  3. elif nota >= 10: --> Caso a primeira condição seja falsa, verifica se a nota é maior ou igual a 10.
  4. else: --> Será executado se nenhuma das condições anteriores for verdadeira.

Resultado: Aprovado

Fluxo de execução

O Python verifica as condições de cima para baixo. Assim que encontra a primeira condição verdadeira, executa aquele bloco de código e ignora os restantes.

Exemplo

nota = 18
if nota >= 16:
    print("Excelente")
elif nota >= 10:
    print("Aprovado")
else:
    print("Reprovado")
  1. O Python verifica primeiro: nota >= 16.
  2. Como a condição é verdadeira, imprime "Excelente".
  3. As estruturas elif e else são ignoradas.

Resultado: Excelente

Laços de Repetição (for, while)

O que são laços de repetição?

Os laços de repetição permitem executar uma mesma tarefa várias vezes sem precisar repetir o mesmo código manualmente.

Imagine que você queira exibir a mensagem:

Olá!
Olá!
Olá!
Olá!
Olá!

Em vez de escrever cinco comandos print(), podemos utilizar um laço de repetição.

O Python possui dois principais laços de repetição:

  1. for
  2. while

Estrutura 'for'

O 'for' é utilizado quando sabemos exatamente quantas vezes queremos repetir uma ação.

Exemplo

for numero in range(5):
    print("Olá!")
  1. for numero in range(5): → Repete o bloco de código cinco vezes.
  2. print("Olá!") → Será executado em cada repetição.

Resultado:
Olá!
Olá!
Olá!
Olá!
Olá!

Utilizando o valor da repetição

Também podemos acessar o valor atual de cada repetição.

Exemplo

for numero in range(5):
    print(numero)
  1. numero recebe um valor diferente em cada repetição.
  2. O print() exibe esse valor.

Resultado:
0
1
2
3
4

Observe que o Python começa a contar a partir do zero.

Definindo início e fim

Também podemos definir onde a contagem começa e onde termina.

Exemplo

for numero in range(1, 6):
    print(numero)
  1. range(1, 6) → Começa no número 1.
  2. O número 6 não será exibido.
  3. O último valor mostrado será o 5.

Resultado:
1
2
3
4
5

Exemplo Prático

Exibindo os números de 1 até 10. 

for numero in range(1, 11):
    print(numero)

Resultado

1
2
3
4
5
6
7
8

Estrutura 'while'

O 'while' é utilizado quando não sabemos exatamente quantas vezes uma repetição irá acontecer.

O laço continuará executando enquanto a condição for verdadeira.

Exemplo

contador = 1

while contador <= 5:
    print(contador)
    contador = contador + 1
  1. contador = 1 → Cria uma variável chamada contador com o valor inicial 1.
  2. while contador <= 5: → Enquanto o contador for menor ou igual a 5, o laço continuará.
  3. print(contador) → Exibe o valor atual do contador.
  4. contador = contador + 1 → Aumenta o contador em 1 a cada repetição.

Resultado:
1
2
3
4
5

A importância de atualizar a condição

Sempre que utilizar um while, é necessário atualizar a variável utilizada na condição. Caso contrário, o programa poderá entrar em um laço infinito.

Exemplo incorreto

contador = 1

while contador <= 5:
    print(contador)

Nesse exemplo, a variável contador nunca é alterada.

Como a condição continuará sendo verdadeira, o programa ficará executando para sempre.

Exemplo correto

contador = 1

while contador <= 5:
    print(contador)
    contador = contador + 1

Agora o contador aumenta em cada repetição e o laço termina quando chegar ao valor 6.

Exemplo Prático

Solicitando uma senha até que ela esteja correta.

Diferença entre 'for' e 'while'

Quando utilizar o 'for'

  1. Quando você sabe quantas vezes deseja repetir.
  2. Quando está percorrendo uma sequência de valores.

Exemplo

for numero in range(10):
    print(numero)

Quando utilizar o 'while'

  1. Quando a repetição depende de uma condição.
  2. Quando não se sabe exatamente quantas repetições acontecerão.

Exemplo

while senha != "1234":
    senha = input("Digite a senha: ")

Funções Úteis

O que são funções?

Funções são comandos prontos que executam tarefas específicas.

Ao longo das aulas já utilizamos algumas funções, como: 

print()
input()
int()
float()

Nesta aula vamos conhecer outras funções úteis que aparecem com frequência em programas Python.

Função 'type()'

A função type() permite descobrir o tipo de dado armazenado em uma variável.

Exemplo

nome = "João"

print(type(nome))
  1. nome = "João" → Cria uma variável contendo um texto.
  2. type(nome) → Descobre o tipo da variável.
  3. print() → Exibe o resultado na tela.

Resultado

<class 'str'>

Outro exemplo

idade = 20

print(type(idade))

Resultado

<class 'int'>

Função 'len()'

A função len() retorna a quantidade de caracteres de um texto.

Exemplo

nome = "Python"

print(len(nome))
  1. len(nome) → Conta quantos caracteres existem na variável.

Resultado

6

Porque:

P y t h o n
1 2 3 4 5 6

Outro exemplo

cidade = "Luanda"

print(len(cidade))

Resultado

6

Função 'round()'

A função round() é utilizada para arredondar números decimais.

Exemplo

numero = 5.8

print(round(numero))

Resultado

6

Arredondando casas decimais

numero = 3.14159

print(round(numero, 2))
  1. round(numero, 2) → Mantém apenas duas casas decimais.

Resultado

3.14

Função 'max()'

A função max() retorna o maior valor entre dois ou mais números.

Exemplo

print(max(10, 20, 30))

Resultado

30

Outro exemplo

nota1 = 15
nota2 = 18

print(max(nota1, nota2))
  1. max(nota1, nota2) → Compara os dois valores.
  2. Retorna o maior valor encontrado.

Resultado

18

Função 'min()'

A função min() retorna o menor valor entre dois ou mais números.

Exemplo

print(min(10, 20, 30))

Resultado

10

Outro exemplo

nota1 = 15
nota2 = 18

print(min(nota1, nota2))
  1. min(nota1, nota2) → Compara os dois valores.
  2. Retorna o menor valor encontrado.

Resultado

15

Função 'abs()'

A função abs() retorna o valor absoluto de um número.

O valor absoluto é sempre positivo.

Exemplo

print(abs(-10))

Resultado

10

Outro exemplo

print(abs(-50))

Resultado

50

Exemplo Prático

Verificando informações sobre um nome. 

nome = input("Digite seu nome: ")

print("Quantidade de letras:", len(nome))
print("Tipo:", type(nome))

Possível execução

Digite seu nome: Manuel

Quantidade de letras: 6
Tipo: <class 'str'>

O programa informa quantas letras o nome possui e também o tipo do dado armazenado.

Exemplo Prático 2

Calculando a maior e a menor nota. 

nota1 = float(input("Digite a primeira nota: "))
nota2 = float(input("Digite a segunda nota: "))
nota3 = float(input("Digite a terceira nota: "))

print("Maior nota:", max(nota1, nota2, nota3))
print("Menor nota:", min(nota1, nota2, nota3))

Possível execução

Digite a primeira nota: 15
Digite a segunda nota: 12
Digite a terceira nota: 18

Maior nota: 18
Menor nota: 12

As funções max() e min() facilitam a comparação entre vários valores, retornando automaticamente o maior e o menor número.
